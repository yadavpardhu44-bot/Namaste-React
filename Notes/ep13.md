# Chapter 13 – Time for the Test

## 1. What are different types of testing?

Testing ensures that our application works as expected and helps prevent bugs.

### A. Manual Testing

* Tester manually checks the application.
* Time-consuming and error-prone.
* Not suitable for large applications.

### B. Automated Testing

* Tests are written in code and executed automatically.
* Faster and more reliable than manual testing.

### Types of Automated Testing

#### 1. Unit Testing

* Tests a single component, function, or module in isolation.
* Smallest level of testing.
* Fast to execute.

**Example:**

```js
function sum(a, b) {
  return a + b;
}
```

Testing:

```js
test("adds two numbers", () => {
  expect(sum(2, 3)).toBe(5);
});
```

#### 2. Integration Testing

* Tests how multiple components work together.
* Ensures communication between modules is correct.

**Example:**

* User types in search box.
* Restaurant list gets filtered correctly.

#### 3. End-to-End (E2E) Testing

* Tests the complete user flow from start to finish.
* Simulates real user behavior.

**Example:**

* Open app
* Login
* Search restaurant
* Add item to cart
* Place order

Popular tools:

* Cypress
* Playwright
* Selenium

## 2. What is Enzyme?

**Enzyme** is a testing utility for React developed by Airbnb.

It provides APIs to:

* Render React components
* Traverse component trees
* Simulate user interactions
* Inspect component state and props

Example:

```js
const wrapper = shallow(<Header />);
expect(wrapper.find("h1").text()).toBe("Namaste React");
```

### Features

* Shallow Rendering
* Full DOM Rendering
* Component Instance Access
* State Inspection

### Limitation

* React updates quickly.
* Enzyme is no longer actively maintained for the latest React versions.
* Modern React projects generally prefer React Testing Library.

## 3. Enzyme vs React Testing Library (RTL)

| Feature                | Enzyme                           | React Testing Library |
| ---------------------- | -------------------------------- | --------------------- |
| Developed By           | Airbnb                           | Testing Library Team  |
| Focus                  | Component internals              | User behavior         |
| State Access           | Directly accessible              | Not accessible        |
| Implementation Details | Tests internals                  | Tests UI output       |
| React Support          | Limited for newer React versions | Excellent             |
| Recommended Today      | ❌ Mostly outdated                | ✅ Preferred           |

### Enzyme Approach

```js
wrapper.state();
wrapper.props();
wrapper.instance();
```

Tests implementation details.

### RTL Approach

```js
screen.getByText("Login");
screen.getByRole("button");
```

Tests what the user sees.

### Why RTL is Preferred?

* Encourages better testing practices.
* Tests application like a real user.
* Less likely to break during refactoring.
* Officially recommended by React community.

## 4. What is Jest and why do we use it?

**Jest** is a JavaScript testing framework developed by Meta (Facebook).

It is used to:

* Run test cases
* Verify expected output
* Generate test reports
* Create mocks and spies
* Measure code coverage

### Installation

```bash
npm install --save-dev jest
```

### Basic Test Example

```js
test("sum of two numbers", () => {
  expect(2 + 3).toBe(5);
});
```

### Common Jest Functions

#### test()

Defines a test case.

```js
test("sample test", () => {});
```

#### expect()

Creates an assertion.

```js
expect(result).toBe(5);
```

#### describe()

Groups related test cases.

```js
describe("Cart Component", () => {
  test("renders cart", () => {});
});
```

#### beforeEach()

Runs before every test.

```js
beforeEach(() => {
  render(<App />);
});
```

#### Mock Functions

```js
jest.fn();
```

Example:

```js
const mockFn = jest.fn();
```

### Benefits of Jest

* Zero configuration setup
* Fast execution
* Snapshot testing support
* Mocking support
* Code coverage reports
* Works seamlessly with React Testing Library

### Jest + React Testing Library

In modern React applications:

```txt
Jest
 └── Test Runner
      └── React Testing Library
             └── Component Testing
```

* **Jest** runs the tests.
* **React Testing Library** helps interact with rendered components.
* Together they form the most common React testing setup.
